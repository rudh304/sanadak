# سندك التقني

موقع تعريفي بمشروع تطبيقي في إدارة مشروع نظم المعلومات، بالعربية (`index.html`) والإنجليزية (`en.html`)، مع وضع داكن.

يعمل الموقع دون إنترنت ودون أي خطوة بناء: افتحي `index.html` مباشرة في المتصفح. الخطوط والأيقونات والرسوم البيانية كلها داخل مجلد `vendor/`، فانقلي المجلد كاملاً دائماً.

## النشر المجاني

**تنبيه:** الموقع يعرض أسماء الطالبات وأرقامهن، وسيتمكن أي شخص لديه الرابط من رؤيتها.

### الطريقة الأولى: Netlify (الأسهل)

1. ادخلي إلى <https://app.netlify.com/drop> وسجّلي الدخول بحساب مجاني.
2. اسحبي مجلد `sanadak` وأفلتيه في الصفحة.
3. انسخي الرابط الذي يظهر بعد الرفع. يمكنك تغيير اسمه من **Site configuration > Change site name**.

### الطريقة الثانية: GitHub Pages

1. ارفعي محتويات المجلد إلى مستودع عام على GitHub، مع الحفاظ على مجلد `vendor/` كما هو.
2. من **Settings > Pages**، اختاري **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واضغطي **Save**.
3. انتظري دقيقة أو دقيقتين، ثم افتحي الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`
